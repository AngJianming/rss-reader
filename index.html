    Problem 8: Count Vowels

Example: count_vowels("hello world") should return 3 count_vowels("AEIOU") should return 5 The Solution Here is the Python implementation: def count_vowels(s): """ Counts the number of vowels in a string. Using a set allows for efficient O(1) lookups. count = 0 Initializes a counter variable count to 0. for char in s: Iterates through each character in the input string s. if char in vowels: Checks if the current character exists in the vowels set. count += 1 If the character is a vowel, increments the count by 1. return count Returns the final count of vowels.
