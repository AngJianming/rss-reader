Transcriber is the answer: a Node.js server that runs Whisper in-process and exposes a single HTTP endpoint. Any browser tool that wants voice input sends audio there and gets text back. Every Machina tool that supports voice uses the same three-level cascade: Level 1 — Web Speech API (Chromium) window.SpeechRecognition is available, use it. Zero latency, zero network. Happy path for Chrome users. Level 2 — Transcriber (port 4324) MediaRecorder captures audio as a webm blob. On stop, it's POSTed to /transcribe. Transcriber converts to WAV with ffmpeg, runs Whisper, returns text. Round-trip: 1–3 seconds. Level 3 — Manual fallback GET /health → { ok, ready, model, language } POST /transcribe → { ok, text } (body: raw audio bytes) POST /shutdown → graceful stop Small surface, single responsibility. Transcriber doesn't manage sessions, doesn't store audio, doesn't know which tool is calling it. The model downloads on first run (~150MB for whisper-base) and caches locally.
