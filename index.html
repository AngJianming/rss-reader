    Exploring Cross Entropy (Part 2): Understanding Total Cross Entropy and Loss with a Python Example
    In the previous article, we went through cross entropy for backpropagation in the case of Softmax. In this article, we will compute the total cross entropy. When we calculate the cross entropy, we get the following values: Setosa = 0.56 To get the total error for the neural network, all we do is add up the cross entropy values. So the total becomes: 0.56 + 0.54 + 0.65 = 1.75 This value, 1.75, is the total cross entropy. We then use backpropagation to adjust the weights and biases in order to minimize this error.
