    ✨ Mastering Object Spread & Rest in JavaScript
    Hey Devs 👋 Today, let’s talk about Object Spread (...) and Rest (...) in JavaScript — two powerful features that often confuse beginners. I’ll keep it simple with examples and a clear takeaway at the end. 🚀 Spread is used to copy, merge, or override properties of objects. const birdDetails = { name: "Crow", color: "black", }; const birdHabitat = { region: "South Africa", climate: "warm to hot", }; const parrotInfo = { ...birdDetails, ...birdHabitat, }; console.log(parrotInfo); // { name: "Crow", color: "black", region: "South Africa", climate: "warm to hot" } Here, both objects are combined into a new object parrotInfo. const car = { brand: "Toyota", name: "Toyota Corolla", color: "white", }; const newCar = { ...car, speed: "220km/h", brand: "Honda", name: "Honda Civic", }; console.log(newCar); // { brand: "Honda", name: "Honda Civic", color: "white", speed: "220km/h" } Notice how brand and name got overwritten after spreading. Rest is used to extract the remaining properties of an object after destructuring some. const student = { name: "Usama", age: 22, grade: "4.5", city: "Karachi", }; const { name, age, ...another } = student; console.log("Directly Remaining properties:", another); console.log("Directly Name and Age:", name, age); // Directly Remaining properties: { grade: "4.5", city: "Karachi" } // Directly Name and Age: Usama 22 function remaProp({ name, age, ...another }) { console.log("Remaining properties:", another); console.log("Name and Age:", name, age); } remaProp(student); // Remaining properties: { grade: "4.5", city: "Karachi" } // Name and Age: Usama 22 Spread (...) → Copy, merge, or override object properties. Rest (...) → Collect leftover properties after extracting specific ones. 🔥 With these two in your toolkit, working with objects in JS becomes much easier! 💡 What’s your favorite use case of spread/rest in JavaScript?
