One CSS rule worth looking for is: /* Removing this without a replacement hides the focus indicator. */ button:focus { outline: none; } Don't remove the default outline just because it looks out of place. Style a replacement instead. :focus-visible lets the browser decide when a visible indicator is needed, while you control its appearance: .cta:focus-visible { outline: 3px solid #1d4ed8; outline-offset: 3px; } This example styles an existing button or link with the cta class. A small manual check: Tab through the navigation, main call to action and form. Check that focus stays visible at each stop. Use Shift+Tab to go back.
